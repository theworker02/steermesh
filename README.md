# steermesh

Steer numeric mesh values, ranges, and human-readable units.

**Site:** https://theworker02.github.io/steermesh/

## Install / run

```bash
git clone https://github.com/theworker02/steermesh.git
cd steermesh
node src/cli.js
node --test
```
